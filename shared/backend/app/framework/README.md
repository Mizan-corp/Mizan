# Framework

The module runtime (ADR-006): the one loader (`loader.py`), the module layout and its tool
(`scaffold.py`, `python manage.py module new|scaffold`), and the pieces still to build:
`manifest.py`, `variants.py`, `hooks.py`, `screens.py`, `settings.py`, `migrations.py`,
`scopes.py`, `isolation.py`, `licences.py` (each file says what it is for and when).
