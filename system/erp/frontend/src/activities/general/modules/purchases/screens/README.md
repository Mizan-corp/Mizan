# Screens

Full pages of `purchases`, one file each (`<Name>Page.tsx`). A variant can replace or add screens.

- `PurchaseOrderPage` (`/purchases/:id`): an order, its receipts, payments and returns, its actions.
- `SuggestionsPage` (`/purchases/suggestions`): products at their reorder point, into a draft order.
- `PriceHistoryPage` (`/purchases/price-history`): a product's purchase costs and suppliers' prices.

The orders list is still `../PurchasesPage.tsx`.
