# Components

Parts used only by this module's screens; shared parts belong in the shared kit (`@/components`).

- `PurchasesHeader`: the title and the purchases tabs.
- `OrderForm`: a new draft or a draft's changes.
- `ReceiveModal`: a goods receipt (quantity, cost, batch, expiry per line; payment with `finance`).
- `ReturnModal`: goods back to the supplier from what arrived.
